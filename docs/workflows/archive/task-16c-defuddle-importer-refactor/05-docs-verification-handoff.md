# Task 16c.5: Documentation, Verification, And PR Handoff

## Goal

Keep project docs aligned with the Defuddle importer boundary and finish the PR
with clear verification evidence.

## Ownership

Primary files:

- `docs/workflows/task-16c-defuddle-importer-refactor.md`
- `docs/research/2026-05-12-url-import-content-extraction-markdown-generation.md`
- `docs/workflows/README.md`

Conditional files:

- `docs/references/technology-stack.md`
- `docs/references/coding-standards/security-boundaries.md`
- `docs/quality/verification.md`

Do not expand `AGENTS.md`. It remains a map.

## Documentation Rules

- Update `technology-stack.md` if Defuddle and the DOM implementation become
  accepted project dependencies.
- Update `security-boundaries.md` only for general rules, such as "external
  extractor output remains untrusted and must not bypass importer fetch
  controls." Do not add one-off PR history.
- Keep the research report as evidence. Do not turn it into a permanent coding
  standard.
- If new fixture commands become required for workers, record them in
  `quality/verification.md`.

## Verification Commands

Run before handoff:

```bash
mise exec -- bun run typecheck
mise exec -- bun run test tests/server/importer/importer.test.ts
mise exec -- bun run test tests/server/importer/extractor.test.ts
mise exec -- bun run test tests/server/memories/add-memory.test.ts
mise exec -- bun run test tests/server/reader/markdown-renderer.test.ts
mise exec -- bun run verify
```

Run only when the branch includes runtime-facing changes or when Task 16 runtime
stabilization is already landed in the target branch:

```bash
mise exec -- bun run test:e2e
```

## PR Handoff Checklist

- State exact `defuddle` and DOM implementation versions.
- State whether `linkedom` or `jsdom` was selected and why.
- State that Defuddle parses only already-fetched bounded HTML.
- State that `useAsync` is disabled or explain the accepted threat model.
- State that persisted Markdown is generated by Trauma's serialization boundary,
  not trusted directly from Defuddle Markdown output.
- Summarize Markdown output differences that matter for users.
- List fallback cases covered by tests.
- Paste exact verification commands and outcomes.

## Acceptance Criteria

- Docs describe the importer boundary accurately.
- No large or one-off review narrative is added to `AGENTS.md`.
- PR handoff contains enough evidence for review without requiring live website
  reproduction.
