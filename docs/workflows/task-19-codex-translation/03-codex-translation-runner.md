# 19.3 Codex translation runner

## Goal

Implement the server-side runner that translates Markdown content through Codex.

This subtask does not add UI.

## Files likely owned

- `src/server/translation/codex-runner.ts`
- `src/server/translation/translate-memory.ts`
- `src/server/translation/prompts.ts`
- `src/server/translation/languages.ts`
- `tests/server/translation/codex-runner.test.ts`
- `tests/server/translation/translate-memory.test.ts`

## Codex execution contract

Use `codex exec` non-interactively.

Recommended command shape:

```sh
codex exec --ephemeral --json --output-schema <schema> -
```

Rules:

- Pass the full prompt through stdin or a temp file, not shell interpolation.
- Use an explicit timeout.
- Capture stdout/stderr separately.
- Treat non-zero exit as translation failure.
- Do not let Codex edit repository files.
- TRAUMA writes the translated `CONTENT.md` after validating output.

## Translation output contract

Use a structured output schema when possible:

```json
{
  "type": "object",
  "properties": {
    "languageCode": { "type": "string" },
    "translatedMarkdown": { "type": "string" },
    "notes": { "type": "string" }
  },
  "required": ["languageCode", "translatedMarkdown"],
  "additionalProperties": false
}
```

Validation:

- `languageCode` must match the requested target language.
- `translatedMarkdown` must be non-empty.
- translated Markdown must not contain source frontmatter unless intentionally generated by the writer.
- translated Markdown must not include Codex commentary outside content.

## Prompt contract

The prompt must instruct Codex to:

- translate the memory body to the target language
- preserve Markdown structure
- preserve links and image destinations
- preserve code blocks without translating code
- translate prose in headings, paragraphs, blockquotes, list items, and table cells
- avoid adding commentary
- return only the requested structured output

## Chunking policy

First implementation may translate a whole memory at once.

If content exceeds a configured size limit:

- split by Markdown block boundaries
- preserve frontmatter outside translation
- translate chunks sequentially
- reassemble in source order
- record partial failures as failed translation, not a partial success

## Tests

Use a fake Codex runner for deterministic tests.

Cover:

- builds safe `codex exec` invocation
- passes prompt through stdin/temp file safely
- validates structured output
- rejects mismatched languageCode
- rejects empty translatedMarkdown
- preserves code blocks in prompt contract tests
- records translation failure on timeout/non-zero exit

## Verification

```sh
mise exec -- bun run test tests/server/translation/codex-runner.test.ts
mise exec -- bun run test tests/server/translation/translate-memory.test.ts
mise exec -- bun run typecheck
```

## Acceptance criteria

- Codex runner is deterministic under tests.
- Translation service can run without exposing credentials.
- App writes output only after validation.
