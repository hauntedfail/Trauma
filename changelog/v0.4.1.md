# TRAUMA 0.4.1

TRAUMA 0.4.1 unifies the visual surface, route chrome, and navigation controls
across Memories, Flashbacks, Moments, Settings, and the Reader, and folds URL
capture into the Command Palette.

## Changed

- Unified Memories, Flashbacks, Moments, Settings, and the Reader on the flat
  canvas ground. Removed permanent boxed list/surface cards and the
  Settings-only gradient, separated list rows and Settings sections with `1px`
  hairline dividers, and reserved surface tint for hover and keyboard selection
  with a `2px` accent bar so moving from any list view into the Reader stays on
  one continuous ground.
- Unified top-level route headers, empty/error states, and archive pagination
  around shared `RouteHeader`, `RouteState`, and `CollectionPagination`
  components.
- Consolidated URL capture into the Command Palette (`Cmd/Ctrl+K` or `a`),
  removing the separate rail and phone Add Memory composer (`AddMemoryForm`)
  while keeping shell-owned URL draft and pending capture state inside the
  palette.
- Redrew the Theme rail icon as a sun and the Settings rail icon as a toothed
  gear.
- Updated design-system documentation and added UI unification E2E assertions
  (`e2e/ui-unification.spec.ts`).

## Fixed

- Fixed a browse hydration race before keyboard triage by setting
  `data-browse-ready="true"` after attaching the browse `keydown` listener and
  synchronizing Shelf keyboard triage E2E tests on it.

## Verification

- Release CI runs the dependency audit, `bun run verify`, and `bun run test:e2e`
  before publishing the GitHub Release for `v0.4.1`.
