# TRAUMA 0.4.0

TRAUMA 0.4.0 rebuilds the interface around a focus-first reading journey:
capture, a short Today list, the Shelf, the Reader, and retrieval from the
Library. It also adds Psychiatrist, a reader assistant scoped to one memory, a
headless agent API, and a round of runtime hardening.

## Added

- Added the focus-first shell: a slim icon-only left rail on desktop, bottom
  tabs on phones, no right rail, and a global `Cmd/Ctrl+K` Command Palette for
  search, navigation, URL capture and focus plugin toggles.
- Added the `Today`, `Shelf`, `Library` and `Archive` triage lanes with flat
  rows, destination-labelled actions, an optional Today cap, and no debt
  counters.
  Shelf triage works from the keyboard: `j`/`k` to move, `p` to Today, `l` to
  Library, `x` to Archive, `Enter` to open, and `u` to undo.
- Added full-text memory search and a single Library Filters popover for
  categories, tags, Flashbacks, archived memories and sort order.
- Added cursor pagination with infinite scroll for memory browse, and lazy
  loading for Flashbacks in browse and in the Reader.
- Added a single-column Reader bound to a `66ch` measure that stays put when
  any popover, panel or sheet opens, with an auto-hiding top bar, selectable
  reading font presets, and typography tuned per language.
- Added the Reader landmark rail: the outline, Moments and Flashbacks in one
  jump list that fills as you read and follows the visible reading range.
- Added reading position persistence. Reopening a memory restores the last
  position silently, and reading 75% of it with at least 20 seconds of dwell
  marks it read.
- Added Psychiatrist, a memory-scoped reader assistant with persisted threads,
  live streaming, stop, regenerate, retry, optional web sources approved per
  turn, and thread backup alongside the memory.
- Added in-situ AI margin notes. Selecting text offers `Simplify`, `Explain`
  and `Ask`; the answer appears beside the passage and can continue in
  Psychiatrist.
- Added the headless agent API under `/api/agent/v1` for reading context,
  reading a memory, triage and passage-grounded questions, with an optional
  `TRAUMA_API_TOKEN` bearer token. See `docs/references/agent-api.md`.
- Added the builtin focus plugins `reading-ruler`, `resumption-beacon`,
  `adaptive-ai-presenter` and `ephemeral-shelf-triage`.
- Added `bun run verify:full`, which runs `verify`, the Playwright browser
  preflight and the full Playwright suite.

## Changed

- Reworked every control to one interaction language. Commands, tools, fields
  and menu rows share a shape and the same focus, pressed, disabled and
  destructive states across the shell, lanes, Reader, capture, Settings,
  dialogs and the browser extension popup. Filter chips and tabs keep a pill
  shape so a selection never reads as a command.
- Reworked Settings into grouped sections.
- Redrew the Library icon as one open book with a visible fold.
- Replaced the five-tab Reader Inspector with small surfaces next to what they
  act on: a translate popover on the language switcher, an overflow menu for
  metadata and management, and the landmark rail.
- Replaced the opaque triage labels with the destination names `Today`,
  `Shelf`, `Library` and `Archive`.
- Moved overlays to Kobalte and Corvu primitives, and confirmation prompts to
  accessible dialogs.
- Changed `bun run verify` to build into `.output-verify/`, so verification no
  longer rewrites the `.output/` directory a running server is serving.
- Changed the runtime to enforce one process per database, artifact store and
  backup root set. A second process reports the owner instead of starting.
- Updated Codex app-server support for current model catalogs and reasoning
  effort constraints.

## Fixed

- Fixed backup durability so failed backup intents, deletions, Flashback
  exports and failsafe recovery survive crashes and retries.
- Fixed migrations to reject invalid histories, tolerate concurrent processes,
  and backfill `word_count` from stored content.
- Fixed unbounded work in translation, Reader projections, event streams and
  collection browse by capping sizes, concurrency and stream lifetimes.
- Fixed browser import and Psychiatrist citations to enforce the host policy.
- Fixed keyboard focus being lost after asynchronous actions, taxonomy
  dismissal, deletion and browse tab changes.
- Fixed phone layouts for Settings and Moments.

## Upgrade Notes

- Run `bun run db:migrate` before starting 0.4.0. The migrations add full-text
  search, triage lanes and reading position. Existing read memories move to
  the Library and unread memories to the Shelf.
- Run a single TRAUMA process per data directory.

## Verification

- Release CI runs the dependency audit, `bun run verify` and `bun run test:e2e`
  before publishing the GitHub Release for `v0.4.0`.
