# TRAUMA 0.2.0

TRAUMA 0.2.0 is the first broad product release after the initial foundation. It
adds the memory action surface, Flashbacks, Moments, taxonomy management,
responsive shell refinements, and a more complete reader workflow.

## Added

- Added read/unread status for memories, including browse and reader controls,
  read-state filtering, and SQLite persistence.
- Added memory deletion across browse and reader views, including SQLite record
  cleanup, memory directory deletion, backup tracking, and explicit backup commit
  actions for delete/update flows.
- Added Flashbacks as the product term and implementation for selected reader
  text, replacing the old highlight language across routes, storage, APIs, and
  UI.
- Added Flashback browse and right-rail surfaces with surrounding context,
  source memory navigation, and deletion actions.
- Added Moments for saved reader sections, including table-of-contents buttons,
  heading affordances, selection-menu actions, route browse, deep links back to
  reader anchors, and delete/toggle support.
- Added category and tag creation, attachment, detachment, browse filtering, and
  right-rail management using shared taxonomy chip components.
- Added `/moments`, `/flashbacks`, and `/settings` routes, plus API routes for
  taxonomy, read status, memory deletion, Flashbacks, Moments, settings, and
  OpenAI auth state.
- Added a shared route header, popup shell, kebab action menu, segmented toggle,
  dismissable layer, scrollable URL text, and reusable taxonomy list controls.
- Added responsive shell support for phone and tablet layouts, including bottom
  tab navigation on phone and compact icon-only navigation on tablet.
- Added theme and design-system refinements for the TRAUMA shell, reader, right
  rail, paper/Hermes surfaces, button hints, native title tooltips, and route
  spacing.
- Added imported media display policy support and reader rendering hardening for
  safer embedded content.
- Added settings storage foundations for translation language and OpenAI auth
  state.
- Added extensive Vitest and Playwright coverage for memory actions, taxonomy,
  Flashbacks, Moments, responsive shell behavior, popup dismissal, reader
  interactions, and backup/delete consistency.

## Changed

- Renamed the product language from highlights to Flashbacks and aligned docs,
  database migrations, routes, tests, and UI labels with the new terminology.
- Reworked the reader layout so memory metadata, actions, URL rendering,
  Flashbacks, Moments, and table-of-contents behavior share consistent
  primitives.
- Reworked the browse page header around read-state tabs and query-synchronised
  search/filter behaviour.
- Reworked right-rail categories, tags, Flashbacks, and table-of-contents
  sections to use shared visual primitives and bounded scroll surfaces.
- Reworked URL rendering so long source URLs remain one-line, horizontally
  scrollable, and constrained to the text hitbox.
- Reworked popup dismissal so outside clicks close the popup without triggering
  the underlying memory row or action, while right-click dismissal does not leave
  stale click suppression.
- Reworked readable extraction to delegate article readability to Defuddle
  instead of maintaining source-specific extraction branches.
- Reworked taxonomy lookup and mutation semantics to use locale-invariant
  matching, exact-name-first lookup, legacy-name support for existing records,
  duplicate attachment prevention, and safer tag/category name validation.
- Reworked release automation so a matching `changelog/vX.Y.Z.md` file becomes
  the GitHub Release body when a semantic version tag is pushed.

## Fixed

- Fixed closed database errors by keeping browse and reader loaders aligned with
  database connection lifetime.
- Fixed partial browser capture imports and importer validation paths that could
  reject valid extracted content.
- Fixed memory deletion inconsistency between SQLite records, stored memory
  files, and backup state.
- Fixed backup commit messages so add, delete, and update actions are
  distinguishable.
- Fixed duplicate taxonomy names and duplicate tag/category attachments,
  including frontend and backend validation boundaries.
- Fixed tag/category mutation edge cases for legacy names, case variants, and
  locale-dependent folding.
- Fixed Moment content hash persistence, Moment toggle behavior, and Moment
  navigation back to the saved reader section.
- Fixed Flashback offset handling around lifted reader titles and anchored
  reader content.
- Fixed source link hitboxes and row action propagation so read toggles, menu
  buttons, and links do not accidentally open the wrong route.
- Fixed popup layering over the main pane, theme/composer popup behavior, and
  Escape handling for stacked dismissable surfaces.
- Fixed reader and browse spacing, route header alignment, right-rail footer
  flow, table-of-contents blur fades, and responsive icon sizing.
